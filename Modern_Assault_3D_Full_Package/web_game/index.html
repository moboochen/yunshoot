如何發布到 GitHub Pages 讓全世界朋友一起玩？

只需 3 個步驟，免安裝任何編譯工具，直接上線！

1
建立 GitHub 倉庫
登入 GitHub 建立一個公開倉庫（如 modern-assault-3d）。
2
上傳 HTML 檔案
將本頁面 index.html 與遊戲主程式 game.html 上傳至倉庫根目錄。
3
開啟 GitHub Pages
在倉庫 Settings > Pages 選擇 Branch 為 main，儲存後即可獲得專屬網址！
